# Contributing to HabitatForge

First off — thanks for even considering it! 🐹

This project was built by a non-developer using AI assistance, so don't be intimidated. All kinds of contributions are welcome.

---

## What can I contribute?

### 🐛 Found a bug?
Open an [Issue](../../issues/new?template=bug_report.md) and describe what happened. Screenshots help a lot.

### 💡 Have an idea?
Open an [Issue](../../issues/new?template=feature_request.md) and describe what you'd like to see.

### 🖨️ Better STL files?
If you've improved a print (better tolerances, cleaner geometry), open a PR with the new `.scad` + `.stl` files.

### 📝 Fixing the docs?
Typos, unclear instructions, missing info — PRs are welcome.

---

## How to submit a Pull Request

1. Fork the repo
2. Make your changes
3. Open a Pull Request with a clear description of what you changed and why
4. That's it — I'll take a look when I can!

---

## A note on pace

I'm not a full-time developer — I'm a geologist who builds things with AI in my spare time.  
I'll do my best to respond, but please be patient. 🙂

---

## Code style

There isn't much of one — but try to keep changes readable and consistent with the existing code.  
If you're adding a new panel type, follow the pattern of existing ones in `habitatforge_v3.html`.
